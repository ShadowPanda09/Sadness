Our project is a 2D top-down PVE arena fighter game, with multiple toggleable classes that can be switched between in battle with their own unique abilities and stats. In addition, whenever the player dies, enemies slow down, up to a maximum of 3 deaths at which the player must restart. It was created by Analeigh Nwokolo and Ryan Schutte using AI tools such as ChatGPT and Gemini.
